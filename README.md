# ECOFLOT

Сайт, CRM и автоматические контуры поиска заявок для ECOFLOT.

## Что входит
- публичный лендинг ecoflot.pro;
- формы заявок и обратного звонка;
- быстрая форма «Срочно нужна машина»;
- CRM с заявками, тендерами, клиентами, автопарком и календарём;
- монитор интернет-заявок;
- монитор Telegram/MAX;
- монитор тендеров;
- Object Leads для поиска новых строек, демонтажа, земляных работ и благоустройства;
- SEO-страницы по услугам и географии;
- sitemap, SEO-аудит, IndexNow и проверка репозитория.

## Основные автоматические workflow
- Internet Leads: 10:00 и 18:00 по Москве
- Social Leads Telegram/MAX: 09:00 по Москве
- Tender Monitor: 11:00 по Москве
- Object Leads: 08:30 по Москве

## Проверки
Перед изменениями в production должны проходить:
- Repository audit
- SEO audit
- GitHub Pages build
