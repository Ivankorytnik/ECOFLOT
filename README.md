# ECOFLOT

CRM и система управления бизнесом по вывозу мусора.

## Текущий прототип
- продающий лендинг;
- форма заявки;
- вход менеджеров по email в демо-режиме;
- CRM-дашборд;
- заявки и продажи;
- календарь занятости флота;
- собственный автопарк;
- привлечённый флот;
- клиенты и аналитика.

Откройте `index.html` для запуска фронтенд-прототипа.
